# 우리집 생활비 절약 계산소 — 배포 및 검색 등록

## 구성
- 16개 작동하는 계산기 페이지, 소개·문의·개인정보처리방침·이용약관, 메인 페이지
- 브라우저 내부에서 계산합니다. 회원가입이나 API 키는 필요하지 않습니다.
- 전력 단가 180원/kWh는 **임의의 비교 예시**입니다. 공식 한국전력 요금이 아닙니다. 누진제·기본요금·세금 등을 반영하지 않습니다.

## 1. 배포 전 반드시 수정
1. contact.html의 `[배포 전 실제 연락 가능한 이메일 주소 입력]`을 실제 이메일로 변경합니다.
2. privacy.html에서 실제 호스팅 및 광고/분석 도구 도입 여부에 맞게 방침을 수정합니다.
3. 사이트 도메인을 확보합니다. `python generate_sitemap.py https://example.com`처럼 **실제 주소**로 사이트맵을 만듭니다.
4. 각 페이지의 title/description과 본문을 검토하고, 사용자가 실제로 유용하게 쓸 수 있는지 확인합니다.
5. 필요하면 실제 도메인의 canonical URL, Open Graph 메타정보를 추가하세요.

## 2. Netlify 배포
1. Netlify에 로그인합니다.
2. Add new project / Deploy manually 등 배포 메뉴에서 이 폴더의 파일을 올립니다.
3. 공개 URL을 확인하고 도메인을 연결합니다.
4. index.html, tools/*.html, sitemap.xml, robots.txt가 모두 200 응답인지 확인합니다.
5. 계정의 배포 한도/크레딧이 부족하면 GitHub Pages나 다른 정적 호스팅을 이용합니다.

## 3. Google Search Console 등록
1. https://search.google.com/search-console 접속.
2. 속성 추가: 도메인 속성(DNS TXT 인증) 또는 URL 접두어 속성(HTML 파일/메타태그 인증)을 선택합니다.
3. 인증용 HTML 파일은 사이트 최상위 폴더에 놓고 다시 배포합니다.
4. 소유권 확인 후 사이트맵 메뉴에서 `https://내도메인/sitemap.xml` 제출.
5. URL 검사로 메인과 대표 계산기 URL의 색인 생성 가능 여부를 확인하고 필요한 경우 색인 생성 요청.
6. 실적 및 페이지 색인 생성 보고서를 주기적으로 확인합니다. 제출 자체가 색인을 보장하지 않습니다.

## 4. 네이버 서치어드바이저 등록
1. https://searchadvisor.naver.com 에서 웹마스터도구 접속.
2. 사이트 등록 후 HTML 파일 업로드 또는 HTML 메타태그로 소유 확인.
3. HTML 파일 방식이면 최상위 폴더에 인증 파일을 추가하고 재배포.
4. 요청 > 사이트맵 제출에서 `https://내도메인/sitemap.xml` 등록.
5. 웹페이지 수집 요청 및 사이트 진단 메뉴를 점검합니다.

## 5. 애드센스 신청 전 점검
- Google AdSense 심사 승인은 보장되지 않습니다. 페이지 개수만으로 승인되지 않습니다.
- 정책 페이지와 실제 문의 이메일을 준비하고, 모바일 가독성·중복 내용·계산 정확도·유용성을 검토하세요.
- 이 사이트의 계산기 설명은 초기 초안입니다. 실측 사례, 검증된 공식 자료, 고유한 비교·예제를 보강하면 더 좋습니다.
- 광고 삽입 시 개인정보처리방침과 동의 관리 요건을 재검토하세요.
- 광고 코드와 ads.txt는 애드센스 계정에서 안내받은 실제 값으로만 설정하세요.
